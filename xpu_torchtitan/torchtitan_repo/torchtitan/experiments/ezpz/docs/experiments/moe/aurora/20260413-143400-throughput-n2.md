## Failed Optimization Attempts

| Experiment | Error | Details |
|-----------|-------|---------|
| MoE 7b TP=2 | DTensor placement mismatch | q,k get Shard(2), v stays Replicate in MLA attention |
| MoE 10b EP=2 | NotImplementedError | EP>1 needs ShardPlacementResult (missing in PyTorch 2.10) |
| MoE 7b EP=2 | same | same PyTorch version issue |
| MoE 500m compile | -35% throughput | Dynamic routing causes recompilations |

## Key Findings

1. **Don't compile MoE models** — dynamic expert routing causes recompilations
2. **MFU plateaus around 11%** for 2b-4b models, drops for 7b+ due to AC=none overhead
3. **7b and 10b require AC=none** — full AC fails with CheckpointError from non-deterministic routing
4. **Memory scales linearly** with model size: 8 GiB (500m) → 55 GiB (10b)
5. **10b at 86% memory** — close to the limit, periodic GC stalls visible
6. **TP>1 broken for MoE** — MLA attention DTensor sharding mismatch
7. **EP>1 blocked** — requires newer PyTorch (missing ShardPlacementResult)
8. **Default LBS is optimal** — larger batch doesn't improve TPS
