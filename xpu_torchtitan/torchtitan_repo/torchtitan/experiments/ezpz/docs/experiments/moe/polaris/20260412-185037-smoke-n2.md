## Notes

- **7B** runs at 89% memory with 136 CUDA allocation retries across 50 steps.
  Severely memory-bound at 1.85% MFU. AC is disabled (`none`) to avoid
  `CheckpointError` from MoE routing non-determinism during AC recomputation.
- **10B_2B_sdpa** uses LBS=1 to fit in memory (76%). Also AC disabled.
  Uses SDPA instead of FlexAttention to avoid Triton compilation issues.
- **500M and 4B** have the best performance characteristics on A100-40GB,
  with enough headroom for larger batch sizes or longer sequences.
