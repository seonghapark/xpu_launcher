## Key Findings

- **TP=1 (pure FSDP) is best** — 27% faster than TP=2 (357 vs 281 TPS)
- **TP adds overhead without benefit** for 20b — the model is too small
  to benefit from weight sharding across TP ranks
- Compile gives **+31% throughput** at TP=1 (est. ~275 no-compile → 357)
- TP=2 compile gives only **+3%** over no-compile (281 vs 272 TPS) —
  compile's fusion gains are offset by TP communication overhead
- Higher TP = less memory but worse throughput: 44.5 → 34.5 → 20.8 GiB
